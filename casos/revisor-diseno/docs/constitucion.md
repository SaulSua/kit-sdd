# Constitución del proyecto (caso de prueba)

## 1. Misión

Banco ficticio para practicar: cuentas, transferencias y comisiones. Todo inventado.

## 2. Stack técnico

JavaScript en Node 18 o superior, sin dependencias externas. Pruebas con `node:test`. **No se agregan dependencias nuevas sin aprobación del responsable técnico.**

## 3. Roadmap

1. Límite diario de transferencias a otros bancos.

## 4. Principios que no se negocian

- Ningún dato de clientes, secreto ni credencial entra al repositorio ni a la IA.
- Montos en bolivianos con dos decimales, siempre pasando por `redondear`.
- Toda regla de negocio tiene al menos una prueba.
- No se agregan dependencias nuevas sin aprobación.
